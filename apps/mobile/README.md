# @registro/mobile

Questa cartella è riservata allo sviluppo della futura applicazione mobile multipiattaforma in **React Native** (fase pianificata nella Roadmap: **Fase 6**).

Caratteristiche previste per l'app mobile:
- Accesso rapido per Studenti, Genitori e Docenti
- Notifiche push per voti, assenze, circolari urgenti e scadenze compiti
- Visualizzazione offline del registro e consultazione appunti scaricati
- Firma delle circolari e giustificazione assenze da smartphone con autenticazione biometrica
